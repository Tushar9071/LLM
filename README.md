## ✨ Features

| Feature | Description |
|---|---|
| 💬 **AI Chat** | Have natural conversations with an AI language tutor. Get instant corrections and explanations with real-time streaming responses. |
| 🎮 **Word Games** | Learn vocabulary through interactive word-meaning matching games. Earn points, XP, and level up your proficiency. |
| ✍️ **Sentence Building** | Practice sentence construction with bilingual sentence pairs generated by AI, tailored to your proficiency level. |
| 🗣️ **Conversation Practice** | Engage in guided conversations where the AI corrects your grammar mistakes in real-time and encourages natural dialogue. |
| 📷 **OCR Scan & Learn** | Scan text in your target language and get instant translations and pronunciations. |
| 🏆 **Gamification (XP & Streaks)** | Earn XP points, maintain daily streaks, and track progress with a comprehensive dashboard. Auto-level-up every 100 points. |
| 📊 **Dashboard** | View your learning statistics, streak information, XP progress, and proficiency levels at a glance. |
| 🌙 **Dark Mode** | Full dark/light theme support with smooth transitions and persistent preferences. |
| 🔐 **Secure Authentication** | JWT-based auth with HTTP-only cookies, OTP email verification, and password reset flow. |
| 🌍 **Multi-language Support** | Set your native language and target language. The AI adapts all exercises accordingly. |

## 🚀 Getting Started

### Prerequisites

| Requirement | Version | Install |
|---|---|---|
| **Node.js** | v18+ | [nodejs.org](https://nodejs.org/) |
| **PostgreSQL** | v15+ | [postgresql.org](https://www.postgresql.org/download/) |

| **npm** | v9+ | Comes with Node.js |

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Tushar9071/LLM.git
cd LLM
```

**2. Install backend dependencies**

```bash
cd backend
npm install
```

**3. Install frontend dependencies**

```bash
cd ../frontend
npm install
```

**4. Configure your AI API**

Set up your preferred AI/LLM provider. Update the backend controller files to point to your custom API endpoint.

### Environment Variables

Create a `.env` file inside the `backend/` directory:

```env
# Database
DATABASE_URL="postgresql://<user>:<password>@localhost:5432/LLM?schema=public"

# Email (for OTP verification)
EMAIL_USER="your-email@gmail.com"
EMAIL_PASS="your-app-password"

# JWT Tokens
ACCESS_TOKEN_SECRET="your-access-token-secret"
ACCESS_TOKEN_EXPIRY_DAYS="1"
REFRESH_TOKEN_SECRET="your-refresh-token-secret"
REFRESH_TOKEN_EXPIRY_DAYS="7"

# AI API (add your custom API key/config here)
# AI_API_KEY="your-api-key"
# AI_API_URL="your-api-endpoint"
```

> **Note:** For Gmail, you'll need to generate an [App Password](https://myaccount.google.com/apppasswords) (2FA must be enabled).

### Database Setup

```bash
cd backend

# Generate Prisma client
npx prisma generate

# Run migrations (creates tables in PostgreSQL)
npx prisma migrate dev --name init

# (Optional) Seed the database
npm run seed
```

### Running the Application

**1. Start the backend** (port 5000)

```bash
cd backend
npm start
```

**2. Start the frontend** (port 5173)

```bash
cd frontend
npm run dev
```

**3. Open in browser**

```
http://localhost:5173
```

## 🔌 API Reference

### Authentication — `/api/auth`

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| `POST` | `/signup` | ❌ | Register a new user (sends OTP to email) |
| `POST` | `/verify-otp` | ❌ | Verify email OTP |
| `POST` | `/login` | ❌ | Login with email/username + password |
| `POST` | `/logout` | ❌ | Logout and clear cookies |
| `GET` | `/get-current-user` | ✅ | Get authenticated user's profile |
| `POST` | `/update-Account-Details` | ✅ | Update user profile settings |
| `POST` | `/setLanguage` | ✅ | Set native + learning language |
| `POST` | `/req-reset-password` | ❌ | Request password reset OTP |
| `POST` | `/reset-password` | ❌ | Reset password with OTP |

### AI Chat — `/api/ai`

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| `POST` | `/aichat` | ✅ | Streamed AI language tutor response |

**Request body:**
```json
{ "message": "How do I say 'hello' in Spanish?" }
```

**Response:** Streamed `text/plain` chunks (Transfer-Encoding: chunked)

### Game & Practice — `/api/game`

| Method | Endpoint | Auth | Description |
|---|---|---|---|
| `POST` | `/wordgame` | ✅ | Generate 5 word-meaning pairs in native → target language |
| `POST` | `/wordgame/addpoint` | ✅ | Award points/XP for correct answers (auto level-up at 100 pts) |
| `POST` | `/makesentence` | ✅ | Generate 5 bilingual sentence pairs for practice |
| `POST` | `/conversationAI` | ✅ | AI conversation partner with grammar correction |

> **✅ Auth** = Requires JWT token via HTTP-only cookie (set on login)

## 🗄️ Database Schema

```
┌──────────┐    1:1    ┌──────────┐
│  users   │──────────▶│ userInfo │
│          │           │          │
│ id       │    1:1    │ avatar   │
│ email    │──────────▶│ dob      │
│ password │           │ gender   │
│ role     │    1:N    │ prefs... │
│          │──────────▶└──────────┘
└──┬───┬───┘
   │   │      1:1    ┌───────────┐
   │   └────────────▶│  session  │
   │                 │  (JWT)    │
   │      1:N        └───────────┘
   │   ┌──────────────────┐
   ├──▶│  userLanguage    │
   │   │  native + target │
   │   │  level, number   │
   │   └──────────────────┘
   │      1:1
   └──▶┌──────────────┐       ┌───────┐
       │  gamePoints   │       │  otp  │
       │  points, xp   │       │ email │
       │  streak       │       │ code  │
       └──────────────┘       └───────┘
```

### Models

| Model | Description |
|---|---|
| **users** | Core user account (email, hashed password, role) |
| **userInfo** | Extended profile (name, avatar, DOB, notification prefs, learning goals) |
| **session** | JWT session tokens with expiry |
| **otp** | Time-limited OTP codes for email verification & password reset |
| **gamePoints** | XP, points, streak tracking per user |
| **userLanguage** | Native & target language, proficiency level (CEFR-based) |
